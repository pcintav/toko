# Kontribusi

Proyek ini untuk latihan SMK RPL. Kontribusi yang membantu siswa belajar lebih disukai daripada fitur yang rumit.

## Cara berkontribusi

1. Fork / clone repo
2. Buat branch fitur kecil (`fitur/nama-singkat`)
3. Ikuti pola yang sudah ada: Express + MySQL (backend), React + Vite (frontend)
4. Jangan commit `.env`, `node_modules`, atau file upload pribadi
5. Jelaskan perubahan di Pull Request (apa & mengapa)

## Yang diutamakan

- Perbaikan bug / typo / komentar edukatif
- Dokumentasi setup (Laragon, seed, akun demo)
- Fitur sederhana yang memperkuat kompetensi RPL (CRUD, validasi, upload, status)

## Yang sebaiknya dihindari dulu

Payment gateway sungguhan, chat realtime, microservice, Redis, testing E2E berat — kecuali dibahas dulu di issue.
